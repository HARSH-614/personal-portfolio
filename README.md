# Sajal Baruah | Personal Developer Portfolio

A futuristic, premium, highly interactive personal developer portfolio built entirely with Vanilla Web Technologies (HTML5, CSS3, ES6+ JavaScript). Designed specifically to highlight a background bridging Physics and Software Development.

## 🚀 Features
- **Glassmorphism UI:** Modern, translucent card aesthetics.
- **Light/Dark Mode:** Built-in theme switcher utilizing CSS variables and `localStorage`.
- **Canvas Visuals:** Lightweight, performance-optimized HTML5 Canvas background drawing scientific orbital nodes.
- **Dynamic Projects System:** Projects are stored in JSON format inside JS, making future updates seamless.
- **Fully Responsive:** Perfect scaling from 320px mobile displays to 4K monitors.
- **Accessible:** Semantic HTML architecture and keyboard navigable.

## 🛠️ Technologies Used
- HTML5 (Semantic Structure)
- CSS3 (Flexbox, Grid, Custom Properties, Animations)
- JavaScript (ES6+, DOM Manipulation, HTML5 Canvas API, Intersection Observer)
- No external libraries (No React/jQuery/Bootstrap) for maximum performance.
